# Little and dumb 2D platformer base made using SFML
> [!NOTE]
>_not intended for publication, but why not_

<sub>_(i don't have any public repositories but i need at least one)_<sub>

No plans for further development

## Controls
- ASD, arrow keys - move
- Spacebar, W, up arrow key - jump
- 1 - select wall
- 2 - select death block
- 3 - select enemy
- RMB - place item
- Mouse scroll - zoom view
- Z - save world
- Esc - return to main menu

## Features
- Scene system (main menu, game)
- Level editor with saving and loading (junky notepad editor)
- Options menu (another junky notepad editor)
- Collision detection using spatial grid
- Collision resolution
- Simple physics stuff
- Animation system
- Camera stuff
- Enemies following player
- Health
